# Image prompts — Les très grands nombres (ChatGPT, 19th-century engraving style)

Style: black wood-engraving / pen-and-ink like the attached reference (the 1884 Tower of Hanoi
engraving). Every drawing is cut out in code: the white paper turns transparent and the lines
take the film's ink, so each drawing looks printed on the film's ivory paper.

**Reference:** attach `style_reference.png` (the cropped 1884 engraving) to every prompt.

How to use:

1. Generate **G01 first, alone**. When you like it, attach G01 (instead of the reference) to
   every later prompt, so the drawings share one hand.
2. Fix with short follow-ups, one change per message ("Same image, fewer people").
3. No colour, no grey wash, no anime, no 3D, no text in the image.
4. Real people are never drawn (Gamow, Lucas, Kasner…): only anonymous figures from a legend.
5. Name each file by its code (`G01.png`, `G02.png`) and upload them here.
