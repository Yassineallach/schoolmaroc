Compose ports of components from Lightswind UI
(https://github.com/codewithMUHILAN/Lightswind-UI-Library, MIT, © 2025 Muhilan).
The React originals are `src/components/ui/{skeleton,count-up,badge,top-loader}.tsx`.
Behaviour and variants follow the originals; colours come from the Nearshelf theme,
and every animation is skipped when the system "Remove animations" setting is on.
