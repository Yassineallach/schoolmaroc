# Image prompts — Histoire des armes

Same storybook-editorial look as the Red Rising film, recoloured for this episode's
"history archive" identity (parchment, walnut ink, oxblood, brass, sepia).

How to use (ChatGPT or any image tool):

1. Generate **P02 first, alone**. When you like it, attach it as the style reference
   for every later prompt and add the line: `Exact same drawing style as the attached image.`
2. Plates (`P`) keep their own painted background — they are used as torn prints.
3. Cut-outs (`C`) go on plain ivory so the code can cut them out cleanly.
4. Fix with short follow-ups, one change per message ("Same image, fewer bones").
5. Never anime, no 3D, no photorealism. Real people are never drawn.

Name the files exactly as the IDs (`P02.png`, `C04.png`, …) and upload them here.
