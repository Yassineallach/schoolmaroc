# Image prompts — L’histoire du sel (ChatGPT, one unified ink-sketch style)

The whole film is drawn in one hand: the black ink sketch of the user's goat reference. Every
drawing is a single subject on plain white: in the video it is cut out (white paper turned into the
film's light paper, lines in the film's ink) and laid on the same parchment background, revealed the
same way, under the same slow camera push, joined by the same torn-paper cut.

**Reference:** attach `style_reference_ink.png` (the user's goat) to **G01**. Once G01 is approved,
attach **G01** instead to every later prompt, so every drawing shares one hand.

Rules:
1. Generate **G01 first, alone**.
2. Fix with short follow-ups, one change per message (« Same drawing, fewer goats »).
3. Black ink only: no colour, no grey wash, no gradients, no 3D, no anime, no text or letters.
4. One subject per drawing, on plain white, no background scenery unless the prompt asks for it.
5. Real people (Gandhi, in act 4) are never generated: see the note at the end.
6. Name each file by its code (`G01.png`, `G02.png`…) and upload them here.
