# Image prompts — L’histoire du sel (ChatGPT, one unified cartoon style)

The whole film is drawn in one hand: the cartoon vector style of the user's reference (a set of
historical warriors). In the video every illustration is shown the same way: full frame, the same
slow camera push, the same cut between shots. No photos.

**G01 approved** (with short black horns, black noses and hooves). **Reference:** attach `style_reference_cartoon.png` (two figures cropped from the user's set) to
**G01**. Once G01 is approved, attach **G01** instead to every later prompt, so every scene shares
one palette and one hand.

Rules:
1. Generate **G01 first, alone**.
2. Fix with short follow-ups, one change per message (« Same image, fewer goats »).
3. No photorealism, no 3D, no anime, no text, letters, logos or watermark in the image.
4. Violence is never shown: no weapons raised, no fighting (the reference is warriors; we keep only the drawing style).
5. Real people (Gandhi, in act 4) are never generated: see the note at the end.
6. Name each file by its code (`G01.png`, `G02.png`…) and upload them here.

The style block that starts every prompt:
```
Use ONLY the illustration style of the attached image: cartoon vector illustration, flat colours with one soft darker shade for shadows and folds, clean shapes with no black outlines, expressive cartoon faces with bold brows and big noses, slightly exaggerated proportions. Warm historical palette: ochre, cream, terracotta, deep red, steel grey, olive, warm browns.
Ignore the warriors, weapons and white background of the attached image; do not copy them.
```
